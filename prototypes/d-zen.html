Type Challenge · 冒泡排序

2021 / 05 / 08 ・ 九分 ・ TypeScript ・ 公開

这题要求在类型系统里实现冒泡排序：给定一个元组 T extends number[]，返回排序后的元组。类型层面上没有循环，所以核心思路是把「一趟冒泡」展开成递归。

一趟冒泡

先写一个 Pass，从头到尾扫一遍，相邻逆序就交换：

bubble.ts 
// 一趟冒泡：相邻比较，逆序则交换
type Pass<T extends number[]> =
  T extends [infer A extends number, infer B extends number, ...infer R extends number[]]
    ? A extends `${B}`
      ? [A, ...Pass<[B, ...R]>]
      : [B, ...Pass<[A, ...R]>]
    : T;

type BubbleSort<T> = ...// 没交换 → 有序
数字比较不能直接用 <，得转成字符串长度或逐位比较——类型体操的老朋友了。

几个细节

  • infer A extends number 收窄推断结果，省掉一层条件判断；
  • 终止条件是「这一趟没有发生任何交换」，用深度相等判断；
  • 元组很长时记得给 TS 足够的递归深度，或者拆成小测试。

完整题解在仓库 type-challenges 里，配合测试用例食用更佳。
