Type Challenge - 冒泡排序

2021-05-08·9 min read·public·#TypeScript

这题要求在类型系统里实现冒泡排序：给定一个元组 T extends number[]，返回排序后的元组。类型层面上没有循环，所以核心思路是把「一趟冒泡」展开成递归。

一趟冒泡：两两比较并交换

先写一个 Pass，从头到尾扫一遍，相邻逆序就交换。它递归地消费元组的头部两个元素：

bubble.ts 
// 一趟冒泡：相邻比较，逆序则交换
type Pass<T extends number[]> =
  T extends [infer A extends number, infer B extends number, ...infer R extends number[]]
    ? A extends `${B}` ? Pass<[B, ...R]> extends infer X extends number[]
        ? [A, ...X]
        : never
    : [B, ...Pass<[A, ...R]>]
    : T;

type BubbleSort<T extends number[]> =
  Pass<T> extends infer P extends number[]
    ? Equal<P, T> extends true
      ? P                       // 一趟下来没交换 → 有序
      : BubbleSort<P>           // 还有逆序对 → 再来一趟
    : never;
数字比较不能直接用 <，得转成字符串长度或逐位比较 —— 类型体操的老朋友了。

几个细节

  • infer A extends number 收窄推断结果，省掉一层 A extends number ? ... : never；
  • 终止条件是「这一趟没有发生任何交换」，用 Equal 做深度相等判断；
  • 元组很长时记得给 TS 配置足够的递归深度，或者拆成小测试。
