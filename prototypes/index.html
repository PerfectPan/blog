UX REDESIGN · PROTOTYPES

整站 UX 改版 · 七个方向的原型

每个方向是一个独立 HTML 文件，内置页面切换器，覆盖站点全部页面： 首页 / 博客列表 / 文章页 / 项目 / 登录 / 注册 / 密码解锁 / 后台列表 / 后台编辑器 / 404 / ⌘K 搜索。 直接点击卡片打开（本地文件，无外部依赖）。

怎么评估这七个方向

  • 每个文件里都有顶部标签栏，点击切换页面；⌘K 搜索面板可以真实唤起，部分方向带小动效。
  • 原型内容用的是真实数据（真实文章标题、真实项目）；少量可见性标记（member/vip/password）为演示虚构。
  • 七个方向都保留现有信息架构与路由（/blog、/blog/:slug 等），只改视觉与交互层，任选其一即可落地。
  • 风格光谱：D 最静 → B/C 克制 → A/E 有性格 → F/G 最张扬。也可以混搭（如 C 的骨架 + B 的正文排版）。
